# Kisan-BhavSathi

Strengthening market linkages and price discovery for farmers.

## About the Project
**Kisan BhavSaathi** is a platform developed for Smart India Hackathon (SIH) 2026. The project is designed to strengthen agricultural market linkages and provide transparent, data-driven price discovery for farmers, Farmer Producer Organizations (FPOs), and agricultural buyers.

---

## Repository Structure

```text
Kisan-BhavSaathi/
├── backend/       # Backend API services and core business logic
├── farmer-app/    # Mobile application for farmers, FPOs, and buyers
├── admin-web/     # Web-based management and monitoring portal
├── docs/          # Architecture, specifications, and project documentation
└── README.md      # Project overview and navigation guide
```

### Folder Roles
- **`backend/`**: Hosts backend services, price discovery engines, data pipelines, and external integrations.
- **`farmer-app/`**: User-facing mobile client providing intuitive, accessible market insights and tools for farmers, FPOs, and buyers.
- **`admin-web/`**: Administrative web dashboard for platform monitoring, data verification, and operational metrics.
- **`docs/`**: Central repository for project documentation, design artifacts, system architecture, and hackathon presentation material.

## Planned Technology Stack

| Component | Technology | Description |
| :--- | :--- | :--- |
| **Backend** | Python + FastAPI | High-performance, asynchronous REST APIs and data processing services |
